# Navalha & Cia

Landing page moderna para uma barbearia premium, com foco em apresentação visual, conversão de clientes e experiência mobile.

## Sobre o projeto

Este projeto é um site institucional para uma barbearia que apresenta:

- apresentação da marca e proposta de valor
- serviços e preços
- linha de produtos
- depoimentos de clientes
- seção de contato e agendamento
- navegação responsiva e interativa

A página foi construída com HTML, CSS e JavaScript puro, oferecendo uma estrutura leve e rápida de carregar.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- Imagens externas do Unsplash

## Estrutura do projeto

```bash
Barbearia/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/ (se necessário no futuro)
```

## Como executar localmente

1. Clone este repositório
2. Acesse a pasta do projeto
3. Abra o arquivo `index.html` no navegador

Ou, se preferir usar um servidor local:

```bash
cd Barbearia
python -m http.server 8000
```

Em seguida, acesse:

```bash
http://localhost:8000
```

## Funcionalidades

- menu responsivo com menu hamburguer
- cabeçalho fixo com efeito de scroll
- seção hero com call-to-action
- cards de serviços com destaque
- vitrine de produtos
- depoimentos com prova social
- formulário de agendamento com validação simples
- animações ao rolar a página
- design com identidade premium e elegante

## Como publicar no Vercel

Se quiser subir o projeto na Vercel:

```bash
npm i -g vercel
vercel
```

Depois, siga as instruções do terminal para concluir o deploy.

## Personalização

Para alterar textos, preços, endereço e WhatsApp, edite os conteúdos diretamente em `index.html`.

Para ajustar cores, tipografia e layout, modifique o arquivo `style.css`.

Para mudar comportamentos interativos, como menu mobile e validação do formulário, edite `script.js`.
